01 · Pendahuluan

Apa itu Active Directory?

Active Directory (AD) adalah layanan direktori proprietary Microsoft untuk Windows Server — pusat penyimpanan data terstruktur mengenai seluruh entitas jaringan: pengguna, komputer, grup, aplikasi, dan perangkat keras.

  • Otentikasi — memverifikasi identitas.
  • Otorisasi — menentukan hak akses.
  • Kebijakan — manajemen terpusat dari satu titik.

📒 Analogi

AD adalah “buku telepon digital terenkripsi” — administrator mengelola identitas & hak akses secara konsisten dari satu titik pusat.

👤 User john.doe Domain: corp.contoso.com
🖥️ Computer WS-FINANCE-01 OU: Workstations
🖨️ Printer HP-MPA01 Site: Jakarta
👥 Group Tier0-Admins Scope: Global

✦ Setiap objek memiliki attributes yang dapat dicari (LDAP query).

05 · Protokol Pendukung & Kelemahannya

NTLM · LDAP · SMB ● coba tab

🪙 Challenge–Response (legacy)

Protokol warisan. Alurnya: server ngirim challenge acak, klien menjawab dengan enkripsi berbasis hash password. Password utuh memang nggak pernah dikirim — tapi jawabannya tetap bisa disalahgunakan lewat dua jalur: hash-nya bisa dipakai langsung sebagai kunci (Pass-the-Hash), dan jawabannya nggak terikat ke sesi tertentu sehingga bisa diteruskan ke server lain (Relay). NTLMv1 wajib dimatikan; NTLM sepenuhnya cukup jadi fallback saja.

⚠️ NTLM = fallback. Matikan bila Kerberos tersedia penuh.

📖 LDAP (389) vs 🔒 LDAPS (636)

Protokol buat baca/tulis database AD. LDAP biasa (port 389) ngirim segalanya dalam plaintext — termasuk kredensial. Nyalakan switch di bawah dan lihat sendiri apa yang “tertangkap” sniffer di jaringan.

08 · Kesimpulan

AD adalah pilar identitas — dan medan perang utama.

  1. Pahami mekanisme Kerberos: tiket, bukan password, yang berpindah.
  2. Kenali titik lemah tiap protokol: NTLM, LDAP plaintext, SMBv1.
  3. Serangan AD mengeksploitasi fitur bawaan — bukan malware eksotis: Kerberoasting, DCSync, Golden Ticket.
  4. Bertahan dengan tiering + LAPS + gMSA + mati protokol legacy.

Krusial untuk pertahanan era hibrida — On-Premises & Entra ID. 🎓
